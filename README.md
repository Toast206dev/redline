Redline is an in-game overlay menu for Forza Horizon 2 on PC (Azimuth, game version 1.0.0.64). Press Insert to open it.

DRIVING
• Boost: extra torque, nitrous with pops & bangs, anti-lag, burnouts
• Launch control: standing, rolling and wheelie launches with RPM hold
• Handling: adjustable drift, extra grip, super brakes, speed limiter
• Stunts: barrel roll, 360 spin, backflip, rocket boost, jump, wheelie mode
• Air control, low gravity and UFO mode (fly the car)
• Ghost mode (drive through traffic) and teleport to saved spots

TOOLS
• Run timers: 0-60 to 0-200 MPH and 1/8 mile to 1 mile, with best times
• Drag mode with a light tree and reaction times
• Real on-screen gauges: speedometer, boost and nitrous, movable and resizable
• Presets, any menu colour, hover help on every setting

GAME
• Build your own upgrade parts (turbos, cams, tyres, wheels, ride height, engine swaps)
• Ready-made packs, AI/traffic cars for sale, free cars (live)
• Add credits, XP and wheelspins to your save (backed up first)

ONLINE (ForzaInfinity)
• Lobby: see players in your world with distance, speed and car; teleport beside them
• Global chat, lobby chat and private messages between Redline users
• Global leaderboard, events with reminders, update notices

Driving effects only change your own car and switch off when Redline closes. Every change to game files or your save is backed up first. The online features use the author's own service; READ ME FIRST.txt explains exactly what is sent, and players can choose whether the author sees their gamertag.

Windows 10/11 64-bit. Run the game in borderless or windowed mode. Unblock the zip before extracting; some antivirus tools flag programs that change a running game.
